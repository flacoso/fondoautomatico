# Fondo Automático

Aplicación Android que cambia periódicamente el fondo usando imágenes de una carpeta seleccionada por el usuario.

- Intervalos: 1, 5, 10 y 15 minutos.
- Modo secuencial o aleatorio.
- Servicio en primer plano.
- Pantalla de inicio y bloqueo.

El APK se genera automáticamente mediante GitHub Actions.
